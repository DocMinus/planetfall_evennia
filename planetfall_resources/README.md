# Planetfall Resources

For convenience, maps and walkthroughs from various sites are collected in this folder, along with one walkthrough written for this port.

Any copyright and intellectual creativity, etc goes to the original authors and those sites.

## Sources

### Walkthroughs

| File | Source |
|---|---|
| [WALKTHROUGH_this_port.txt](WALKTHROUGH_this_port.txt) | **Written for this port.** Paul D. Smith's compact walkthrough (below), corrected so every command works here as typed. The test suite (`world/test_walkthrough_doc.py`) replays it verbatim and requires a winning 80/80 game, so it stays in step with the port |
| [detailed_walkthough.txt](detailed_walkthough.txt) | Planetfall walkthrough at [eristic.net](http://www.eristic.net/games/infocom/planetfall.html) |
| [detailed_walkthrough.md](detailed_walkthrough.md) | The same eristic.net walkthrough, reformatted as Markdown with light rewording |
| [compact_walkthrough.txt](compact_walkthrough.txt) | `planetfall.step1` by Paul D. Smith (1992), from the [IF Archive](https://ifarchive.org/if-archive/infocom/hints/solutions/planetfall.step1). Written for the original game; a few steps don't work as-is in this port (see `WALKTHROUGH_this_port.txt`) |
